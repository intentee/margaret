# `margaret_example` crate rules

- `margaret_example` must demonstrate all the framework feature
- `margaret_example` must be invocable from CLI
- `margaret_example` must implement an entirely working realistic (but as simple as possible) CRUD application (a blog) that keeps all the articles in memory
- `margaret_example` must implement best practices when it comes to security (they just need to be simplified to the maximum, because this needs to be a simple, understandable example)
